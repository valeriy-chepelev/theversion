# The Version

![Build](https://github.com/valeriy-chepelev/theversion/actions/workflows/build-windows.yml/badge.svg)

Утилита для синхронизации версий очередей Yandex Tracker.

## Возможности

- Просмотр объединенной таблицы версий выбранного набора очередей Yandex Tracker
- Изменение описания версий (многострочность поддерживается)
- Изменение флагов архивации версий
- Установка флагов релиза версий (отмена релиза не поддерживается)
- Запись объединенной таблицы и изменений на сервер в выбранный набор очередей

## Установка

Готовые сборки для Windows — во вкладке [Releases](../../releases).

Распакуйте архив и запустите `TheVersion.exe`.

## Настройка

Настройте файл `theversion.ini`, удалив расширение `.example`:

```ini
[DEFAULT]
token = <OAuth-токен Yandex Tracker> - получить у администрации
org = <ID организации> - получить у администрации
prefix = <префикс версий через запятую>
queues = <перечень тегов очередей через запятую>
```
Можно использовать token с доступом только на чтение -
тогда запись данных на сервер будет недоступна.

Поддерживается org_id и cloud_org_id.

Префикс версий - начальный текст наименования, общий для версий,
например, для "ARM_v.1.1", "ARM_v.1.2" - префикс "ARM".

## Рабочий сценарий

#### Запустить утилиту - выведет таблицу версий первого префикса во всех очередях.

Версии очередей с идентичным наименованием считаются одной и той же версией. Сравнение нечувствительно к регистру.

Если в любой из очередей версия отмечена Архивной или Релизной,
в таблице будет включен соответствующий переключатель.

Если в очередях для одной и той же версии заданы разные описания - они будут объединены
через точку с запятой.

#### Выбрать очереди и префикс версии.
Таблица обновится. Для обновления также можно нажать "Обновить".

Данные из отключенных очередей игнорируются.

#### Проверить и исправить информацию.

#### Выбрать очереди для записи данных.

#### Нажать "Сохранить" для записи данных.

Все версии и их информация сохраняются в выбранные очереди.

Если в очереди нет такой версии - она будет создана; если есть - её
данные будут обновлены.

## Запуск из исходников
```bash
pip install -r requirements.txt
python src/theversion/__init__.py
```

## Сборка
Сборка выполняется автоматически в GitHub Actions при пуше тега v*.
Локально:
```bash
flet pack src/theversion/__init__.py --onedir --name TheVersion
```
